# 도화지 App Store 1.0 심사 자료

## 제품 페이지

- 이름: `도화지`
- 부제: `함께 만드는 모임 동선 지도`
- 기본 카테고리: 내비게이션
- 보조 카테고리: 여행
- 연령 등급: 4+

### 프로모션 문구

핀과 메모, 손그림으로 약속 지도를 만들고 실제 이동 경로와 중간지점까지 한 번에 확인하세요. 앱이 없는 사람에게도 웹 링크로 그대로 공유할 수 있습니다.

### 설명

도화지는 여러 장소와 사람의 이동을 한 장의 지도에 담는 모임 동선 앱입니다.

장소를 단계별로 정리하고, 한 단계에 여러 후보를 함께 올린 뒤 대표 장소를 고를 수 있습니다. 도보·대중교통·자전거 이동수단에 맞춘 실제 경로와 거리, 예상 시간을 지도에서 확인하세요.

주요 기능

• 지도 위 장소를 길게 누르거나 검색해 단계와 후보 추가  
• 단계별 복수 후보와 대표 장소 지정  
• 도보·대중교통·자전거 실제 이동 경로  
• 참가자별 이동수단을 반영한 중간지점 후보  
• 메모, 핀, 손그림으로 지도 위에 필요한 정보 기록  
• 폴더와 다양한 마크로 장소 보관함 정리  
• 만든 지도를 링크로 공유 — 앱이 없는 사람도 웹에서 확인  
• 로그인 없이 바로 시작하고 기기에 초안 자동 저장

현재 위치는 사용자가 현재 위치 버튼을 누를 때 지도 화면을 이동하는 용도로만 사용합니다.

## App Review 메모

도화지는 로그인이 필요하지 않습니다.

주요 확인 경로:

1. 지도에서 장소를 길게 누르거나 ‘장소 추가’를 눌러 장소를 단계에 담습니다.
2. 왼쪽 ‘단계’ 버튼에서 후보/대표 장소와 다음 구간 이동수단을 설정합니다.
3. 사이드 메뉴의 ‘중간지점 찾기’에서 참가자별 출발지와 이동수단을 입력합니다.
4. ‘공유하기’는 생성된 웹 링크를 iOS 공유 시트로 전달합니다.
5. Share Extension은 다른 지도 앱이 공유한 텍스트/URL을 도화지 보관함에 담습니다.

위치 권한은 지도 왼쪽 아래 현재 위치 버튼을 누를 때만 요청하며, 지속 추적하거나 현재 위치를 서버에 저장하지 않습니다. 앱 내 구입, 광고, 계정 생성은 없습니다. 지도/장소 검색 및 경로 계산에는 Kakao Maps SDK와 서버 API를 사용합니다.
